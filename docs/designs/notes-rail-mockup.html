HUD Notes: left rail (mockup, ticket 9a4a9d5e)

The tab strip, the ‹ › arrows and the ▾ list are gone. Every note is a row in a rail on the left: pinned notes first in your own drag order, then everything else unread first, then newest. The search box matches names and contents. The rail collapses to a thin strip and can be resized from its right edge. The header badge and read tracking are unchanged. The first frame is live: type in the search, click rows, pin and unpin, and collapse or expand it.

1. Live: dark, normal width

Try searching for deploy or merge. Hover a row for pin ⟂, rename ✎ and delete ✕. A pinned row also shows a drag grip ⋮⋮. A dot marks a note that is unread. ✦ marks a note an agent wrote; hover it to see who.

2. Light, normal width: search with a match highlighted

"redeploy" matches one note's name, and the text of two others. Those rows show a one-line snippet with the match, because their names alone would not tell you why they are listed.

3. Dark: rename, delete confirm, drag within pinned

Double-click (or ✎) renames in place. ✕ asks in the row, with the same confirm as today. Dragging only works inside the pinned group; the line shows where the note will land.

4. Light, normal width: rail collapsed

A 30px strip: expand », the unread count, and + new note. The editor gets the full width.

5. Dark, narrow HUD: collapsed by default

Below about 380px the rail starts collapsed, so the editor stays usable.

6. Light, narrow HUD: rail opened over the editor

When the HUD is narrow, expanding the rail lays it over the editor. Picking a note (or clicking outside) closes it again.

7. Dark, resizing the rail

Drag the rail's right edge (highlighted). The width is remembered.

What each mark means

  • Pinned group: your notes, in your drag order. Pin or unpin with ⟂ on the row. Only you can pin; an agent's new note always arrives unpinned.
  • Notes group: everything else, sorted unread first, then by last change, newest first. There is no drag here, so automatic order and manual order never mix.
  • ● unread: an agent wrote or changed the note since you last saw it. ✦ an agent wrote it (the tooltip says which one). The time is the last change.
  • The HUD tab header badge counts unread notes exactly as it does today.
