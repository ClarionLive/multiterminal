HUD Notes: left rail (mockup, ticket 9a4a9d5e, revision 2)

Every note is a row in a rail on the left. Pinned notes come first, in your own drag order. Every other note sits under its category, sorted unread first, then newest. Each note picks its category from a dropdown above the editor: the default is General, and the top entry is Add…. Rows have no hover icons any more. Right-click a note to pin, rename, change category or delete it. The first frame is live: right-click a row, change a note's category (try Add…), collapse a group, search, or collapse the rail.

1. Live: dark, normal width

Right-click any row. Click a category header to fold it. Use the Category dropdown above the editor; Add… creates a category on the spot. Search for restart or merge.

2. Dark: the right-click menu

The menu offers Pin, Rename, Category ▸ (every category plus Add…) and Delete. The row it acts on stays outlined while the menu is open.

3. Light: the Category dropdown, adding one

Add… sits on top, then the existing categories, General first. Choosing Add… turns that line into a text box; Enter creates the category and files the note under it.

4. Dark: rename, delete confirm, drag within Pinned, a folded group

Rename (from the menu, or double-click) edits in place. Delete asks inside the rail. Dragging works only inside Pinned. A folded group keeps its count and an unread dot, so nothing hides.

5. Light, normal width: search with a match highlighted

Searching for "restart": only groups with a match stay visible. A name match is highlighted. A note that matches only in its text (the pinned Todo) shows a snippet, so you can see why it is listed.

6. Light, normal width: rail collapsed

A 30px strip: expand », the unread count, and + new note.

7. Dark, narrow HUD: collapsed by default

Below about 380px the rail starts collapsed, so the editor stays usable.

8. Light, narrow HUD: rail opened over the editor

When the HUD is narrow, the rail opens over the editor. Picking a note, or clicking outside, closes it.

9. Dark, resizing the rail; right-click on a category

Drag the rail's right edge to resize it; the width is remembered. Right-clicking a category header lets you rename or delete that category. Deleting one moves its notes to General.

What each mark means

  • Pinned: your notes, in your drag order, whatever their category. Only you can pin. An agent's new note always arrives unpinned.
  • Category groups: General first, then the rest alphabetically. Each group is sorted unread first, then newest. Drag ordering does not apply here.
  • Categories are one shared list, the same in every project, which keeps them consistent. Only you add them. An agent may file its note under an existing category; an unknown one lands in General.
  • ● unread: an agent wrote or changed the note since you last saw it. ✦ an agent wrote it (the tooltip says which one). The time is the last change.
  • The note you have selected keeps its place until you pick another one, even though reading it (or typing in it) would re-sort it. Try it in frame 1.
  • The HUD tab header badge counts unread notes, as it does today.
